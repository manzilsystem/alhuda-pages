# منظومة الهدى

بوابة ملاك عربية ثابتة تُنشر على GitHub Pages. صفحة البداية تعرض معلومات عامة فقط، ولا تحتوي على بيانات شخصية أو حسابات وحدات.

## البنية

- `index.html` بوابة الملاك العامة، بتصميم مستقل عن لوحة الإدارة.
- `admin.html` لوحة الإدارة، وتفتح مباشرة من مسار `/admin.html`؛ لا يوجد رابط لها في بوابة الملاك.
- `.github/workflows/pages.yml` ينشر الصفحتين والهوية البصرية باستخدام GitHub Actions عند كل تحديث لفرع `main`.
- مستودع خاص منفصل `alhuda-vault` يحفظ `vault.json` بعد تشفيره في المتصفح باستخدام AES-GCM ومفتاح مشتق من عبارة مرور المدير.
- يتصل التطبيق مباشرة بواجهة GitHub REST API. رمز الوصول يُطلب عند دخول المدير ويبقى في ذاكرة الصفحة فقط، ولا يُحفظ أو يُرسل إلى مستودع الموقع.

## الإعداد الأول

1. أنشئ مستودعًا عامًا باسم `alhuda-pages` لكود الموقع. GitHub Free يتطلب أن يكون مستودع موقع Pages عامًا.
2. أنشئ مستودعًا خاصًا باسم `alhuda-vault` وأضف ملف README كي يوجد فرع `main`.
3. في إعدادات المستودع العام، افتح **Settings → Pages** واختر **GitHub Actions** كمصدر النشر. سير العمل ينشر صفحة الملاك وصفحة الإدارة والملفات اللازمة لهما.
4. أنشئ fine-grained personal access token مخصصًا لمستودع `alhuda-vault` وحده، بصلاحية **Contents: Read and write**. أدخله في نموذج دخول المدير عند الاستخدام؛ لا تضعه في الشفرة أو أسرار النشر.
5. افتح موقع Pages، وأدخل حساب GitHub واسم مستودع الخزانة والرمز وعبارة مرور طويلة. في أول دخول ينشئ التطبيق ملف خزانة جديدًا مشفّرًا.

## حدود وأمان

- GitHub Pages ملفات ثابتة فقط. لا يوفر جلسات خادم أو مصادقة آمنة لكل مالك؛ لذلك تعرض بوابة الملاك محتوى عامًا فقط. لا تضع إعلانات سرية أو أرصدة وحدات أو أسماء أو أرقام هواتف في `index.html` أو أي ملف منشور.
- لوحة الإدارة تتطلب من المدير رمز GitHub وعبارة مرور الخزانة في الجلسة؛ لا تشارك رابط `admin.html` على أنه بوابة خاصة، فالشفرة نفسها عامة.
- اجعل مستودع الخزانة خاصًا. محتوى `vault.json` مشفّر، لكن سجل GitHub يكشف وقت التعديلات وحجمًا تقريبيًا للملف.
- استخدم رمزًا دقيقًا مخصصًا لمستودع الخزانة وبأقل صلاحيات لازمة. الشفرة العامة تستطيع قراءة الرمز أثناء الجلسة، لذلك راجع تغييرات الموقع وسير النشر قبل إدخال الرمز.
- نسيان عبارة المرور يعني عدم إمكان فك الخزانة. تحتفظ إصدارات GitHub الخاصة بنسخ سابقة مشفّرة.
- لا يدعم التطبيق الكتابة المتزامنة من أكثر من مدير؛ GitHub يرفض التعارض كي لا يستبدل تعديلًا أحدث.
- سجل السكان الموجود في المستودع القديم لا يُنقل تلقائيًا. لا ترفع بيانات شخصية إلا بعد التأكد من إزالة المستودع القديم العام أو حمايته.

كل التشغيل والتخزين والنشر يبقى داخل GitHub. تحتاج إدارة الخزانة اتصالًا بالإنترنت ورمز GitHub صالحًا.
